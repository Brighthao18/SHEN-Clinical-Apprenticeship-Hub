# 完全合成演示

这里的文本、图片、OCR 和固定结构化响应从零构造，不来自真实病例的改名脱敏。原图由文本排版生成，没有医院标识。固定密码/密钥是公开测试值，只用于演示。

前两次使用同一演示 MRN，日期不同，覆盖白术/炒白术、丹参移除、黄芪加入、茯苓未知剂量。第三份故意缺少 MRN，期望 UNRESOLVED。注册表按 OCR 文本 SHA-256 精确查找；未知输入仍拒绝。

seed_demo.py 通过认证 API 上传图片与明确 mock OCR，等待真实 Celery/Validator 链路，确认患者匹配及未解决记录没有临床写入，再创建一份用户作品。为了展示确定性处方变化，种子通过现有确认接口录入四个人工编写的合成字典映射（白术、炒白术、丹参、黄芪）；茯苓故意保留待标准化与未知克数，不添加任何医院规格。它们仅适用于本演示，不是模型建议的自动确认。重复运行按来源 hash 去重，已有作品和已修改字典不覆盖。不提供真实 AI 准确率证据。

界面常驻合成标识；API、worker 等后端服务只接 internal 网络，Web 另接仅发布本机端口的入口网络。构建需要联网；不宣称所有容器都没有外网能力。正式 Compose 不挂载本目录、不装种子。许可 Apache-2.0，copyright 2026 FU HAO。
