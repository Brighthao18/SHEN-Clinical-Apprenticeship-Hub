# 隐私与服务确认

公开版默认不启用真实服务。开源许可不包含云服务凭证、服务额度或数据处理授权。每位部署者需核对实际服务条款和数据范围，然后在当前实例中逐服务确认。默认值和旧部署的个人授权不得当作新部署的同意。

| 路径 | 可能发送的内容 | 当前边界 |
| --- | --- | --- |
| MinerU OCR | 原始图片/PDF，可能包含姓名、病历号等 | 显式开启并确认原图上传；默认 mock |
| ClinicalAIExtractor | 原始 OCR 文本，可能包含姓名、病历号等 | 保留现有逐服务确认；默认 mock，不声称文本已脱敏 |
| Vision Verification | 原始图片及指定缺失字段核验请求 | 功能默认关闭，仅已有白名单阻断问题触发一次；需原图上传确认 |
| 病程分析 / 师承写作 | 脱敏临床上下文、确定性变化与证据引用 | 各自配置；不是公开数据，临床内容仍需保护 |

2026-10-05 的公开版决定是保留明确告知与逐服务确认，默认关闭真实服务。[OPEN_DECISIONS](OPEN_DECISIONS.md)记录该边界。这里修正了早期“一切云端 AI 仅接收脱敏文本”的笼统说明；没有新增脱敏抽取算法，也没有改变冻结的摄取行为。

设置页按服务插槽保存配置，Key 加密存储，返回结果与日志不显示 Key。原图/OCR 抽取与脱敏分析分属不同的数据边界，确认一项不代表确认全部。生产默认只有本机 Web/API，文件经认证接口读取，身份存储与临床 Patient 分离。日志使用稳定 ID；不要向 Issue、CI、截图、模型反馈或公开附件提供真实来源或环境文件。

缺失内容保持 NULL/未记录。AI 只能在既有 schema、OCR 证据及 Validator 门控内重述来源；不为演示降低校验。分析与学习理解使用推断标记，不能成为医生诊断或老师口述。UNRESOLVED 保留证据，不写临床事实；重新处理为显式命令。

演示使用独立端口、数据卷与公开固定密码。API、worker、数据库、队列和种子只接 Docker internal 网络，不能访问外网；Web 另接入口网络，以便发布 localhost:3200。入口网络没有阻断 Web 的外网能力，但 Web 不持有外部模型凭证，后端使用 mock。下载构建依赖需要联网，演示运行中不调用外部 OCR/AI。请勿上传真实患者资料。生产网络可访问配置服务，因此必须遵守其显式许可，不能因为“本地优先”宣称完全离线。网络设计依据 [Docker 官方说明](https://docs.docker.com/engine/network/)与[端口发布说明](https://docs.docker.com/engine/network/port-publishing/)。
