# 开始使用

先从[根 README](../README.md)中的无密钥演示开始。首次构建需要联网；后端运行网络隔离外网，网页通过单独入口网络在本机访问。演示只包含从零构造的图片、OCR、固定抽取响应和一份用户作品。

登录后查看导入页面：前两份资料已导入，同属一个合成患者；第三份因为缺少关键身份信息保持 UNRESOLVED。打开患者时间线，核对来源文件、处方项目和未知剂量。比较两次就诊，观察增减、炮制和剂量变化。作品页可以编辑、保存草稿、保存最终版、查看历史并导出 Markdown；重新保存追加版本。

mock 不是一个真实 OCR 或医学模型。导入新文件时没有对应固定响应会失败关闭；演示种子通过原图、明确 OCR 文本和严格 hash 注册表走实际摄取链，不证明 AI 准确率。自动 AI 分析与写作需要配置专用服务，在演示中不可调用外网。

停止保留数据用 `docker compose --env-file examples/demo/demo.env -f compose.demo.yaml stop`。重新运行演示启动命令会保留资料并按 hash 去重。如果确实要清空演示，可在确认仅需删除合成数据后使用同一配置执行 `down --volumes`；不要把此命令用在正式实例。

端口 3200 已占用时先核对占用者；不要自动结束不明进程。Docker 未启动或依赖下载中断时检查 Docker 状态和网络，然后重试。启动失败可读取 `docker compose --env-file examples/demo/demo.env -f compose.demo.yaml logs --tail 50 seed`，它只处理合成记录；正式日志不得原样贴到公开 Issue。

保存真实资料前，另建[正式部署](deployment.md)，在本机生成新密钥。演示的存储、账户和许可不迁移为真实环境授权。
