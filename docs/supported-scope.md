# 支持范围

当前为单用户本地师承资料整理预览版。个人使用；课题组成员可分别部署和集成，不使用共享管理员账户宣称多人协作。新部署不继承任何既往资料上传许可。

现有 JNU 门诊和旧版处方规则是范围边界：`(10g)2包` 表示每剂 20 g；旧版每药直接克数也是每剂，诊号不是病历号。课程总量不能替代每剂剂量。新医院必须独立验证身份锚点、单位、每剂/疗程语义、药名、缺失与反例，不能只替换医院名称就认为已适配。

当前提供不可变来源、患者时间线、确定性处方变化、脱敏纵向 AI 分析、跟师笔记和医案的追加版本。不提供多人权限、HIS/FHIR、RAG、类似医案、老师规律分析、舌象诊断、语音、学习心得/月度总结生成或富文本。

已测环境和检查以[本候选验证记录](validation.md)为准。目标部署为 Windows x64 + Docker Linux amd64 容器，CI 设计为 Linux amd64；macOS、ARM、NAS、离线本地 OCR/LLM 待验证。OpenAI-compatible 接口不意味着所有平台/模型原生支持；模型名与 Key 由用户提供，严格 JSON 和逐服务许可仍须验证。

导入保守运行：Validator 通过才提交，未通过保持 UNRESOLVED。不设基于样本数量的使用前置门槛，也不从工程检查、样本计数或未确认 Gold 推导准确率、机构合规或 Production Ready。
