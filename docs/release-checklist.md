# 候选发布检查

逐项核对当前提交，真实病例不进入任何环节。保存的本地证据可包含工具输出，但公開附件只允许审阅过的合成摘要。

- LICENSE / NOTICE 的主体为 FU HAO，第三方依赖版本、许可原文、图标及容器摘要有清单；不打包权重、医院资料或机构标识。
- Git 跟踪树与 release-manifest.json 路径/hash 完全对应；检查提交作者、标签、压缩包、合成截图与镜像。旧 private Git 历史没有复制。
- 使用发布源码的新目录/克隆运行安装、演示。确认不知道原电脑私有文件也能启动；生产配置不用旧密钥，默认真实服务关闭，无演示挂载/注册表。
- 后端测试与静态检查、前端类型/单测/lint/构建、隔离 PostgreSQL 空库迁移与 Alembic check、E2E、容器健康均有当前证据；失败不能忽略。
- UNRESOLVED 无临床行、hash 幂等、未知剂量、确定性炮制/剂量变化、追加作品版本与认证保持。
- Valkey 验证真实 Celery broker/result backend、重启持久任务、结果 TTL 和失败重试；不从 redis-py 导入成功推导兼容。
- 使用合成资料完成带 hash 清单的备份和隔离数据库恢复；不覆盖现有库。restic 如未实测明确标注。
- 构建上下文和最终镜像分别检查，用合成哨兵模拟禁止路径，禁止读取实际私有目录。
- 确认四条数据边界、支持矩阵、实际平台、未实现功能；不得声称临床准确率、所有医院或 Production Ready。
- CI 在真实公开仓库运行后再宣称 CI 通过；启用私密漏洞入口。公开地址/发布/镜像推送需要持有人最终发布决定。

发布工作流只生成当前提交的源码包、hash 和清单，不自动创建公开仓库、不推镜像。`.github/workflows/release.yml` 手动触发或候选标签触发，权限只读。候选标签只可用于已验收提交。
